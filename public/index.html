Installation
Three steps, no dev tools

Download one file, drop it in a folder, open Excel. If you have an agent like Claude Code or Excelerate AI handy, you can just ask it to do all of this for you.

1 Download the manifest

This small file tells Excel where to find Excelerate AI. It's the only thing you need to download.

manifest.prod.xml

2 Copy it to Excel's add-in folder

Open Terminal and paste this. It creates the folder if needed and copies the file.

$ mkdir -p ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef && \
  cp ~/Downloads/manifest.prod.xml ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/
Saved it somewhere other than Downloads? Change ~/Downloads/ to wherever you put it.

3 Open Excelerate AI in Excel

  1. Quit Excel completely (⌘Q) and reopen it
  2. Go to Home → Add-ins
  3. Click Excelerate AI to open the sidebar
Heads up — Pi was built and tested on macOS. It should work on Windows (the underlying tech is cross-platform) but hasn't been extensively tested. Worth a try! If you hit issues, open a GitHub issue.

1 Download the manifest

Same file — a small config that tells Excel where to find Excelerate AI.

manifest.prod.xml

2 Upload it in Excel

  1. Open Excel
  2. Go to Insert → My Add-ins → Upload My Add-in…
  3. Select the manifest.prod.xml file you downloaded
Important: use Upload My Add-in… for this file — not Manage → XML Expansion Packs. That older Excel path can show misleading certificate errors for Office add-in manifests.

3 Open the sidebar

Click Open Excelerate AI in the ribbon.

MAKE IT YOURS

One sidebar.
Your favorite models.

Connect OpenRouter directly

Open Settings → Custom gateway. Add your OpenRouter API key and these settings:

Endpoint: https://openrouter.ai/api/v1
Model: nex-agi/nex-n2.5-mini:free
Max context tokens: 262144

OpenRouter connects directly; no local proxy is needed for this connection. Choose Update gateway, then select the model in your chat. Free model availability and provider limits apply.

Connect with an API key

In the Excel sidebar, type /login, choose your provider, and save your key. Provider usage charges apply.

Use a supported subscription

Some providers need a local proxy for browser login. Run this in Terminal, then sign in from the sidebar:

ALLOWED_ORIGINS=https://excel.stwk.site npx pi-for-excel-proxy

The proxy runs on your computer. Keep it running while using connections that require it.

Alternative upstream installer
curl -fsSL https://piforexcel.com/proxy | sh

For this custom domain, configure the proxy’s ALLOWED_ORIGINS to https://excel.stwk.site. The command above is the simplest route when Node.js is installed.
